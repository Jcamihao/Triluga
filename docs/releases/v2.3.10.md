# Release Notes v2.3.10 - Triluga

Data: `2026-05-11`

## Resumo

A versão 2.3.10 padroniza o marketplace para usar preço semanal de ponta a ponta e melhora a publicação de anúncios com validação guiada por etapa.

## Entregas principais

- filtros, ordenação e alertas de busca passam a comparar preço semanal
- criação e edição de veículos tratam `weeklyRate` como preço principal, mantendo `dailyRate` apenas como compatibilidade legada
- cards, favoritos, comparação, chat, perfil público e detalhe do veículo exibem preço por semana
- conversas, favoritos e perfis retornam `weeklyRate` no payload do backend
- painel do proprietário leva o usuário para a etapa com campos obrigatórios pendentes e exibe mensagens mais específicas
- seleção de seguro no cadastro do anúncio usa alteração explícita de estado
- documentação Swagger ajustada para descrever `minPrice` e `maxPrice` como faixa semanal

## Validação

- `npm run build`

## Observações

- O frontend compila com avisos de budget CSS já existentes em componentes acima do limite configurado.
