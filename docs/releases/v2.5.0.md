# Release v2.5.0

Esta é uma grande atualização focada em segurança, identidade do usuário, verificação de dados e melhorias na UX do marketplace.

## 🚀 Novas Funcionalidades (Features)

* **Sistema de Verificação de Identidade com IA (OCR):** Foi introduzido um onboarding completo para envio de selfies e documentos (CNH, RG). O sistema utiliza Tesseract OCR avançado e IA no backend para validar identidades e garantir a legitimidade dos anunciantes no Triluga.
* **Verificação de E-mail:** Agora os usuários precisam verificar o endereço de e-mail ao criar a conta. O fluxo inclui envio via SMTP, banners interativos de aviso, link de reenvio de confirmação, guardas de rota (Guards) para impedir ações críticas de contas não confirmadas, e atualização de estado imediata na interface.
* **Recuperação de Senha (Forgot/Reset Password):** Fluxo completo de "Esqueci minha senha", incluindo envio de e-mails com token temporário e telas otimizadas para redefinição segura de credenciais.
* **Envio Real de E-mails:** Módulo `EmailService` e processor de notificações usando fila (BullMQ) + `Nodemailer` e configurações SMTP nativas, substituindo envios falsos/simulados por e-mails reais.
* **Integração Completa de Endereços no Mapa:** O mapa do veículo (Google Maps embutido e links externos) agora prioriza o endereço completo digitado pelo anunciante, apontando a localização com precisão de quadra/rua.
* **Tabela FIPE:** O card de preço do veículo agora exibe automaticamente o valor da Tabela FIPE como comparativo para ajudar nas negociações.
* **Central de Privacidade (LGPD) Renovada:** Layout da central de privacidade foi melhorado com novos links para termos de serviço no onboarding.
* **Componentes Split (Mobile e Desktop):** Divisão final e organização dos componentes de Perfil do Usuário para se adequar a diferentes telas, recebendo novos campos nativos do anunciante.

## 🐛 Correções de Bugs (Fixes)
* Corrigido um bug onde o usuário era deslogado acidentalmente ao retornar do fluxo de verificação de e-mail por abortamento de chamada de refresh de token.
* Removida variável órfã `PLATFORM_FEE_RATE` que gerava ruído nos logs.
* Ajustes no payload de JWT para prevenir falhas de acesso e melhoria no log de erros (upstream failures).

## 🔧 Refatorações e Melhorias de Desempenho
* Refatoração massiva da página de Compare, Chat e Vehicle Detail, que agora possuem versões assíncronas dedicadas para Mobile e Desktop.
* Dashboard do Proprietário otimizada.
* Modelagem do Banco (Prisma) atualizada com novas tabelas de tokens de redefinição e dados confidenciais do usuário.
