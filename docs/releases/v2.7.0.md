## 🗑️ Remoção da verificação de identidade (KYC)

O fluxo de KYC (upload de selfie, documento e CNH + verificação por IA) foi removido do produto — decisão de escopo, não bug.

- **Backend**: apagado o módulo `verification/` (OCR via Tesseract.js, análise via Ollama, comparação biométrica via InsightFace), os endpoints de upload/status em `profiles` e `admin`, e o bucket privado do MinIO (existia só para isso).
- **Banco de dados**: migration remove os campos de KYC do `Profile` (`documentImageUrl`, `driverLicenseImageUrl`, `selfieImageUrl`, `documentOcrText`, `cnhOcrText`, `documentVerificationStatus`, `driverLicenseVerification`) e o enum `VerificationStatus`. Os campos `documentNumber`/`driverLicenseNumber` (apenas números digitados, sem arquivo) foram mantidos.
- **Infraestrutura**: removidos do `docker-compose.yml` os serviços `ollama`, `ollama-pull` e `face-verification`; apagada a pasta `face-verification/` (microserviço Python/FastAPI + InsightFace) e a dependência `tesseract.js`.
- **Frontend**: removida toda a UI de upload/status de verificação (perfil próprio e painel admin), o modal de onboarding de verificação, e os badges "Membro Premium"/"Identidade verificada" no card de veículo, detalhe do veículo e perfil público.
- **Documentação/LGPD**: `privacy-policy.md`, `lgpd-operations.md` e `data-retention.md` atualizados para remover menções a coleta/retenção de documento, CNH e selfie.

## 🗺️ Localização real do anúncio no mapa

O mapa da página de detalhe do veículo dependia só de geocoding textual do endereço digitado no anúncio (sem captura de latitude/longitude), o que podia mostrar o pin no lugar errado quando cidade/estado/endereço eram inconsistentes entre si.

- **Novo endpoint** `GET /lookups/geocode` — geocodifica endereço via Nominatim (OpenStreetMap, gratuito, sem API key), cacheado no Redis.
- **Wizard de anúncio**: o campo "Endereço de retirada" agora dispara geocoding automático ao perder o foco, gravando `latitude`/`longitude` reais no veículo, com feedback visual (localização encontrada / não encontrada).
- Removido o campo "Estado" duplicado no 2º passo do wizard — cidade/estado agora só são definidos uma vez, no 1º passo.
