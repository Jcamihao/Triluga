# Release Notes v2.3.11 - Triluga

Data: `2026-05-11`

## Resumo

A versão 2.3.11 oculta a feature de salvar alertas de preço na busca, removendo botões, feedback visual e acionamento no frontend.

## Entregas principais

- botão mobile "Criar Alerta de Preço" removido da tela de busca
- feedback de salvamento de alerta removido da interface
- fluxo Angular de criação de alerta retirado da página de busca
- dependências da página de busca para autenticação e API de alertas removidas

## Validação

- `npm run build`

## Observações

- O backend de alertas permanece no código, mas sem entrada visível pela busca.
- O frontend compila com avisos de budget CSS já existentes em componentes acima do limite configurado.
