# Release Notes v2.4.14 - Triluga

Data: `2026-06-03`

## Resumo

A versão 2.4.14 adiciona uma galeria de imagens responsiva na página de detalhe do veículo, com suporte a zoom, navegação por toque e carrossel interativo para melhorar a experiência de visualização dos anúncios.

## Entregas principais

- galeria de imagens responsiva implementada na página de detalhe do veículo
- suporte a zoom nas fotos com controle por gesto ou clique
- navegação por toque (swipe) entre as imagens da galeria
- carrossel interativo com miniaturas para acesso rápido a cada foto
- ajustes de estilo no cabeçalho web para alinhamento visual com a galeria

## Impacto técnico

- `vehicle-detail-page.component.ts` expandido com lógica de galeria, zoom e gestos (~205 linhas adicionadas)
- `vehicle-detail-page.component.html` refatorado para suportar o novo layout de galeria
- `vehicle-detail-page.component.scss` com novos estilos responsivos para galeria e zoom
- sem novas dependências externas adicionadas

## Validação

- `npm --prefix frontend run build`
- `npm --prefix backend run build`
