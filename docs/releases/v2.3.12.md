# Release Notes v2.3.12 - Triluga

Data: `2026-05-30`

## Resumo

A versão 2.3.12 melhora o fluxo de imagens do Triluga, com edição de fotos no anúncio, crop de avatar no cadastro e otimização automática dos uploads públicos para reduzir uso de disco em produção.

## Entregas principais

- fotos do anúncio agora exibem ações para remover ou substituir cada imagem selecionada
- limite visual e validação de fotos do anúncio alinhados em 5 imagens
- cadastro abre uma modal de ajuste ao selecionar foto de perfil
- crop de avatar permite arrastar, aplicar zoom e salvar a imagem enquadrada
- backend converte imagens públicas para WebP antes de salvar no MinIO
- fotos de veículos são limitadas a 1600x1200 com compressão balanceada
- avatares são limitados a 768x768 com compressão balanceada

## Impacto técnico

- adicionada dependência `sharp` no backend para processamento de imagens
- documentos privados continuam sendo enviados sem conversão automática
- imagens antigas no MinIO não são reprocessadas por esta release

## Validação

- `npm --prefix frontend run build`
- `npm --prefix backend run build`

## Observações

- O frontend compila com avisos de budget CSS já existentes em componentes acima do limite configurado.
