## 🤖 InsightFace — Verificação Biométrica no KYC

A verificação de identidade agora combina dois modelos em paralelo: o Ollama (`qwen2.5-vl`) para análise de documentos e o **InsightFace** (`buffalo_s`) para comparação biométrica real entre a selfie e as fotos dos documentos.

- **Novo microserviço Python** (`face-verification/`) com FastAPI + InsightFace rodando no Docker Compose.
- **Cosine similarity** entre embeddings normalizados da selfie ↔ documento e selfie ↔ CNH (threshold `≥ 0.40`).
- **Modelos persistidos em volume** Docker (`face-models`) — download único na primeira inicialização (~100 MB).
- **Degradação graciosa**: se o serviço de face estiver indisponível, o KYC continua usando apenas o Ollama.
- **Ollama e InsightFace rodam em paralelo** — sem impacto no tempo de resposta do KYC.

## 🚀 CI/CD com GitHub Actions

Pipeline automático para garantir qualidade antes de cada deploy.

- **CI** (`ci.yml`): build Angular + build NestJS + ESLint + `npm audit` em todo push para qualquer branch.
- **CD** (`cd.yml`): dispara após CI verde no `master` — SSH na VPS → `git pull` → `docker compose up --build` → limpeza automática de cache de build.
- **Limpeza de cache**: `docker builder prune --force` após cada deploy evita acúmulo de GB em disco na VPS.

- **Variável de ambiente**: `FACE_VERIFICATION_URL` (padrão: `http://face-verification:8000`).
